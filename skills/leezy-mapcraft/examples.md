# LEEZY MapCraft · 调用参考

作者：[BigWai1312](https://github.com/BigWai1312) · 来源：https://github.com/BigWai1312/leezy-skills

以下均是任务模板。替换尖括号内的内容；不存在的数据写“无”，不要把示例当作实际计算结果。

## 1. 从表格和面数据制作专题图

```text
$leezy-mapcraft
制作 <年份><研究区><指标名称> 乡镇分布图。
乡镇面：<路径>；乡镇编码字段：<字段>
指标表：<路径与工作表>；编码字段：<字段>
指标字段：<字段>；单位：<单位>
DEM：<路径>；河流：<路径>；道路：<路径或无>
ArcPy 环境：<python.exe>；输出目录：<路径>
核对编码类型、重复编码、连接率、缺失值和指标范围。
根据实际分布建议分级方法，记录阈值，不把缺失值当成零。
水系蓝色，专题设色避开蓝色；不要把资源丰度高值渲染成风险警示。
直接制作独立专题图，不先制作概况图，不把任何概况图成图铺在下面。
地形按需淡化或关闭；图例右下两列，只有确需细节时才放城区放大图。
中文宋体，英文和数字 Times New Roman；经纬度图廓，600 dpi JPG。
输出 APRX、本地数据、PNG 预览和 QA 说明。先做一张，确认后再批量。
```

预期交付：连接核查与缺失说明、一张可编辑地图、预览及导出图。若只有区县数据空间分配到乡镇，须在独立方法说明中标为估算，不称为乡镇实测。

## 2. 只调整现有地图

```text
$leezy-mapcraft
打开 <APRX路径>，另存到 <新路径>。
保持现有指标、几何和分级阈值，仅调整制图表现。
缩减留白，图名进图框；指北针右上，图例右下。
图例左列为指标分级，右列为水系、道路和区划说明。
白色图例底板必须覆盖两列，并位于全部图例文字和符号下方。
县界用灰色虚线，河流与主干道适当加粗。
分别导出带装饰性边界阴影和不带阴影的预览，供我比较。
```

预期交付：另存的工程和两张对比预览；原工程及源数据保持完整。阴影只用于视觉，不参与空间计算。

## 3. 编写离线手工制图教程

```text
$leezy-mapcraft
依据 <字段表与指标说明>，写 ArcGIS Pro 手工制图 Markdown。
我在离线电脑上制作，已有行政区、道路、水系和 DEM。
逐图说明导入哪些数据、连接哪个字段、如何核查匹配结果。
写出分类字段、各级阈值、图例名称、RGB、透明度和线宽。
图例、经纬度图廓、比例尺、指北针的位置及字体均要明确。
基础地理数据可以共用，逐项列出复用的独立图层和符号设置。
每张图独立建立地图和布局，重做对应标题、图例、单位和分级。
不要写成复制上一张成图，也不要把概况图PNG/PDF当专题底图。
分类字段用 1 至 5 的整数码时，另列对应阈值，保留原始数值字段。
不运行计算、不修改数据、不插入 Word，只输出教程。
```

预期交付：可逐项操作的 Markdown。若实际软件是 ArcMap 10.2，明确要求该版本教程，不能用 APRX 或 Pro 专有操作替代。

## 4. 审核已有地图与分析表达

```text
$leezy-mapcraft
检查 <地图图片或APRX>，结合 <指标表和方法说明> 提建议。
检查色带含义、图例范围、单位、数据年份、缺失值和标注遮挡。
先列影响读图或结论的具体问题，再提出改图方案。
仅在有可核验数据时写 2 至 3 段空间分析；不要从底图外观推断因果。
未提供邻接关系和统计检验时，不声称存在显著空间聚集。
暂不修改工程或报告。
```

预期交付：有依据的审查意见和可追溯分析；没有计算的数据明确列为未验证。

## 5. 只列基础数据清单

```text
$leezy-mapcraft
我要做湖南省及周边的 GIS 底图，专题指标稍后由我自己提供。
先看 <本地数据目录>，列出已有、缺少和待核验的基础数据。
范围为湖南省边界外包矩形长边乘1.4的正方形，在米制投影中计算。
清单列用途、必要字段、优先级、覆盖范围和验收要求。
这次只列清单，等我要求收集时再下载，不处理数据、不制图。
```

预期交付：基础数据清单与范围解释。没有边界时说明范围待计算，不编造坐标，不下载 GIS 数据。

## 6. 自动补齐基础数据

```text
$leezy-mapcraft
现在开始为 <研究区> 准备离线基础地理数据。
已有目录：<目录>；项目目录：<目录>；边界：<路径或无>。
专题指标我自己做，本次只负责基础数据。
先查本地，自动获取缺失的区划、DEM、水系、水面、主要交通和地名。
DEM 要实际下载并检查，优先合适的约30米数据，不能只给服务地址。
包括周边行政区，县级边界留作备用；区位小图资料按需。
采用默认扩大40%边长的正方形范围，所有环境图层覆盖它。
检查来源版本、坐标系、缺块、接缝、偏移、中文名称和分类字段。
保留原件，将中间文件、制图副本和最终交付按项目约定分开。
交付离线数据、范围文件、来源清单、QA预览及未解决问题。
不计算专题指标，不制作最终专题图。
```

预期交付：经过核验的基础数据包；无法获取或无法核验的图层明确列出。自动获取只使用可用的公开来源或已有授权，不虚构下载成功。

## 7. 紧凑的区域概况图

```text
$leezy-mapcraft
用 <已核验基础数据目录> 制作 <研究区> 概况图。
保留采集时1.4倍边长的覆盖余量，主图默认显示1.2倍边长的正方形。
地图框保持在已核验覆盖内，研究区边界不能被裁切。
缺失必要底图时先自动补齐；专题指标暂不加入。
角落放白底细框的全国区位小图，突出研究区；主要图例靠右下。
省域图廓用整度，少留纸面白边，图名加白色光晕，市州界适当加粗。
地形起伏适中，图例左右留足内边距，不挡研究区及其边界阴影。
无必要的来源小字放配套说明，数据许可要求的可见署名仍保留。
输出可编辑工程、PNG、PDF及QA说明。
```

预期交付：研究区完整、周边适量的概况图，全国小图有独立完整素材与不透底的白色背景。1.2倍显示范围下，外包框长边约占图框83%；若明确要求显示1.4倍或其他更大范围，按指定范围制作，不擅自收紧。

## 8. 没有基础数据，直接制作概况图

```text
$leezy-mapcraft
为 <省或市名称> 做一张区域概况图，目前没有基础数据。
在当前项目内查找可复用资料，自动获取缺少的必要基础数据及全国区位素材。
专题指标后面由我提供，这次不做专题数据。
DEM 实际下载到本地，核验真实分辨率、完整覆盖和NoData后再生成晕渲。
先发现可用的GIS执行环境，完成数据核验、可编辑工程和PNG/PDF。
原件、中间数据、脚本、成果按项目约定存放；列出仍有的缺口。
```

预期交付：实际离线基础图层和地图，而非只有数据网站清单。受限数据、缺少许可或运行环境等问题具体说明；可完成的独立步骤继续做，不虚报已完成。若用户另行指定30米，粗分辨率预览不能代替该要求。

## 9. 只柔化当前地形

```text
$leezy-mapcraft
当前地图起伏太大，稍微柔和一点。
只降低晕渲夸张和明暗对比，保留全国小图、20%显示范围、图例及文字位置。
高程原值不要变，先保留旧版本，更新工程、导出图和QA记录。
```

预期交付：局部调整后的同版式地图。按当前实际参数小幅回调，不重新获取已有合格数据，不改指标和几何；重新生成相应派生栅格，检查最终图片后再标记视觉通过。

## 10. 已有概况图，独立制作指标栅格专题图

```text
$leezy-mapcraft
为 <研究区> 制作 <年份><指标名称> 专题图。
指标栅格：<路径>；单位：<单位>；NoData含义：<说明>。
现有概况图工程：<APRX路径>；基础地理数据：<GDB或目录>。
只复用已核验的基础数据和需要的独立图层，不使用概况图PNG/PDF。
建立独立地图和布局，保留原概况图；不额外生成新的概况图。
指标栅格为主体，核验范围、投影、NoData和色带含义，不重算指标。
边界、水体、地名按需显示，地形淡化或关闭；标题和图例按本指标重做。
输出到 <新目录>，交付可编辑工程、PNG/PDF和QA记录。
```

预期交付：独立的指标专题图。概况图与专题图可以共用同一GDB，但不是同一张地图换标题；即使没有概况图，也可直接从指标与基础数据制作专题图。
