# LEEZY MapCraft · 调用参考

作者：[BigWai1312](https://github.com/BigWai1312) · 来源：https://github.com/BigWai1312/leezy-skills

以下均是任务模板。替换尖括号内的内容；不存在的数据写“无”，不要把示例当作实际计算结果。

## 1. 从表格和面数据制作专题图

```text
$leezy-mapcraft
制作 <年份><研究区><指标名称> 乡镇分布图。
乡镇面：<路径>；乡镇编码字段：<字段>
指标表：<路径与工作表>；编码字段：<字段>
指标字段：<字段>；单位：<单位>
DEM：<路径>；河流：<路径>；道路：<路径或无>
ArcPy 环境：<python.exe>；输出目录：<路径>
核对编码类型、重复编码、连接率、缺失值和指标范围。
根据实际分布建议分级方法，记录阈值，不把缺失值当成零。
水系蓝色，专题设色避开蓝色；不要把资源丰度高值渲染成风险警示。
DEM 铺满图框，起伏适当夸张；图例右下两列，城区放大图左上。
中文宋体，英文和数字 Times New Roman；经纬度图廓，600 dpi JPG。
输出 APRX、本地数据、PNG 预览和 QA 说明。先做一张，确认后再批量。
```

预期交付：连接核查与缺失说明、一张可编辑地图、预览及导出图。若只有区县数据空间分配到乡镇，须在独立方法说明中标为估算，不称为乡镇实测。

## 2. 只调整现有地图

```text
$leezy-mapcraft
打开 <APRX路径>，另存到 <新路径>。
保持现有指标、几何和分级阈值，仅调整制图表现。
缩减留白，图名进图框；指北针右上，图例右下。
图例左列为指标分级，右列为水系、道路和区划说明。
白色图例底板必须覆盖两列，并位于全部图例文字和符号下方。
县界用灰色虚线，河流与主干道适当加粗。
分别导出带装饰性边界阴影和不带阴影的预览，供我比较。
```

预期交付：另存的工程和两张对比预览；原工程及源数据保持完整。阴影只用于视觉，不参与空间计算。

## 3. 编写离线手工制图教程

```text
$leezy-mapcraft
依据 <字段表与指标说明>，写 ArcGIS Pro 手工制图 Markdown。
我在离线电脑上制作，已有行政区、道路、水系和 DEM。
逐图说明导入哪些数据、连接哪个字段、如何核查匹配结果。
写出分类字段、各级阈值、图例名称、RGB、透明度和线宽。
图例、经纬度图廓、比例尺、指北针的位置及字体均要明确。
公共底图和整饰标注为“从上一张图复制”，同时说明需重新调整的项。
分类字段用 1 至 5 的整数码时，另列对应阈值，保留原始数值字段。
不运行计算、不修改数据、不插入 Word，只输出教程。
```

预期交付：可逐项操作的 Markdown。若实际软件是 ArcMap 10.2，明确要求该版本教程，不能用 APRX 或 Pro 专有操作替代。

## 4. 审核已有地图与分析表达

```text
$leezy-mapcraft
检查 <地图图片或APRX>，结合 <指标表和方法说明> 提建议。
检查色带含义、图例范围、单位、数据年份、缺失值和标注遮挡。
先列影响读图或结论的具体问题，再提出改图方案。
仅在有可核验数据时写 2 至 3 段空间分析；不要从底图外观推断因果。
未提供邻接关系和统计检验时，不声称存在显著空间聚集。
暂不修改工程或报告。
```

预期交付：有依据的审查意见和可追溯分析；没有计算的数据明确列为未验证。
