# 湖南概况图示例说明

[查看原尺寸图片](../assets/demo-preview.png)

本图是实际完成的湖南省区域概况图，采用 2026-11-16 导出的版本，地形晕渲已按反馈从 5 倍回调到 3.5 倍。公开预览与该版本的 PNG 字节一致，没有重新绘制或用合成纹理替代地形。

它展示概况图的版式与基础地理表达，不含 SDG 指标，不是专题图示例，也不是供其他地图直接加载的底图。使用本技能制作专题图时，应读取自己的指标和基础图层，独立建立地图、标题和图例。

## 可核对的显示参数

| 项目 | 本图设置 |
| --- | --- |
| 图片 | 3804 × 3804 像素，300 dpi |
| 主图范围 | 投影外包框长边的 1.2 倍正方形；保留 1.4 倍采集覆盖 |
| 地形 | 约 449.1 m 派生网格，3.5 倍制图晕渲；原高程未放大 |
| 标注 | 整度经纬度、市州名称、图名白色光晕 |
| 图例 | 右下两列，左右 12 pt、上下 10 pt 内边距 |
| 区位 | 左下独立全国示意图框，湖南突出显示 |
| 研究区 | 省界与市州界分层；边界外阴影仅作装饰 |

原工程的检查记录包含 14 个市州名称、0 个断链图层、0 个在线图层，以及图例与湖南边界及其阴影无面状重叠。这些检查针对这一份成果，不代表任意来源、软件环境或后续制图都会自动通过。

| 图层 | 来源 | 说明 |
