# PowerPoint制作与检查

## 模板复用

默认资产：`assets/blue-white-briefing.pptx`，一张内容样板页，不是强制封面。

命名对象：

- `SC_Title`：标题。
- `SC_Lead`：引句。
- `SC_Conclusion`：总结句。
- `SC_SlideNumber`：母版内的原生动态页码。

复制样板或复用其母版与版式来创建用户要求的总页数。正文区域留给图表和原生流程图，不把模板提示文字留进交付。

保留源PPTX中的母版与主题，避免只采样颜色后另建一套近似版式。用户给了其他模板时先读取并渲染，遵循其层级与写法。使用内置模板的字号和位置不代表可以忽略内容适配。

## 现有稿件修改与合并

1. 找到用户真正指定的版本，读取页数、主题、画布、图表、GIF和备注。保存必要的源文件哈希与私有工作副本。
2. 按用户指定顺序合并，保留原页。需要成果1—4等分组时创建原生节，统一章节名称或标题前缀。
3. 内容衔接优先通过已有引句或讲稿备注完成。未经要求不添加封面、过渡页，不删减重要结果。
4. 检查同为16:9的文件是否具有不同的实际画布尺寸。缩放容器后，原生图表的字号、线宽和标记可能没有同步缩放；表格字号也可能被取整，造成“区”等单字孤行。
5. 对照原稿调整确实受影响的图表、表格和标题，不把合并任务扩大为全面重设计。
6. 在最后版本上验证正文、图表序列与类别、图片/GIF、备注及必要的原始工作簿仍在。

## 自动页码

本模板已在母版中使用原生 `slidenum` 字段，新增或调序时跟随页序，不使用固定总页数。

用户通常复制同一成果的邻近页继续编辑，既延续版式也继承页码。复制到另一成果时，标题中的成果编号和原生节归属仍需相应调整，它们不等于全稿页码。

对于其他已有稿件，可在Windows PowerPoint环境使用：

```powershell
pwsh -File scripts/number-slides.ps1 `
  -InputPath "input.pptx" `
  -OutputPath "output-numbered.pptx" `
  -FontName "微软雅黑"
```

脚本仅在新副本中统一页码，不覆盖原稿，不删除随意匹配的数字。运行前处理已经确认的手填页码；脚本会关闭原生旧页码占位符并替换本技能自己的编号字段。

脚本遇到隐藏母版图形的页面会停止，避免重新显示用户刻意隐藏的图形。此时按实际页面结构单独处理，不盲目把 `DisplayMasterShapes` 打开。

不同来源PPT新增了另一套母版时，先检查是否继承编号。在本稿版式中新建和复制已编号页最可靠；不要承诺任意外部PPT直接粘贴都会自动适配。

验证应使用测试副本：插入新页、复制现有页、删除一页、移动末页到开头，分别查看实际渲染中的页码；之后交付未被测试操作改变的正式稿。

## 图表可编辑性

- 仅看到原生图表对象不等于其“编辑数据”链接完整。核查图表引用的嵌入工作簿、数据缓存、类别及系列是否对应。
- 保留原始工作簿、公式和数据来源。发现引用错误时先查原稿，不能直接重建一张看起来相似的图。
- 若原稿只有完整的图表内嵌常量且原本没有工作簿，确需恢复数据编辑能力时，可以用同一组已有数值生成图表数据快照。记录快照性质，不冒称恢复了原始模型公式。
- 对已有工作簿的图表，修复缓存应来自该工作簿。浮点字符串差异只做显示无影响的精度整理，并检验数值等价，不重算或改写研究结论。
- 图表位置、大小和字体调整后重新渲染。数据对了，不代表类别标签齐全或轴线可读。

## 工具选择

优先复用当前项目可运行的PPTX生成和验证工具。可用的原生PowerPoint路径适合保留主题、自动编号和现有对象；其他成熟工具也可用，但须说明无法验证的宿主功能。

不要求安装某个硬编码路径下的插件或Node/Python版本。有适用的演示文稿技能或工具时，按其接口和限制执行；工具缺失时说明具体缺口，不声称已在PowerPoint实测。

不在用户请求的普通流程图里用图片替代所有文字与箭头。地图、照片和GIF属于图像素材，可保持图像形式；数值趋势与关键示意图优先保留原生可编辑结构。

## 最终检查

| 检查层 | 必须分清的事实 |
| --- | --- |
| 内容 | 获准Markdown是否覆盖，数字、单位、年份、成果归属是否正确 |
| 结构 | 页序、章节、对象、图表数据、图片、GIF及备注是否完整 |
| 视觉 | 逐页实际渲染，无裁切、遮挡、错位、浅灰小字和图例丢失 |
| 增页维护 | 原生页码随新增、复制、删除、调序更新 |
| 宿主打开 | 指明实际打开的软件，不能把结构检查写成宿主验证 |
| 放映 | 实播检查GIF、平滑切换；未测则标明未测 |

只交付当前检查过的版本。自动检查报告与临时渲染放私有构建目录；不因检查提示而改写无关正文或强制统一原稿的所有图表样式。
