# 视觉与证据规范

## 默认蓝白样式

内置模板是已经认可的项目汇报样式的去项目化版本。内容区保持平面、留白和明确主次，不将整页拆成装饰性卡片。

| 元素 | 本模板参考值 | 使用原则 |
| --- | --- | --- |
| 画布 | 960 × 540 pt，16:9 | 其他画布按实际物理尺寸处理 |
| 标题 | 微软雅黑，约28 pt，黑色 | 标题清楚、完整，不压到装饰条 |
| 引句 | 约19 pt，深蓝 `#00008B` | 一到两行，不改成方法段落 |
| 结论 | 约17 pt，黑色，适当加粗 | 一到两行，与引句及主体不重叠 |
| 主色 | `#0167B1`，白底 | 不强行统一所有数据系列为同一色 |
| 次要文字 | 深灰，参考 `#303946` | 投影可读，避免浅灰小字 |
| 流程连接 | 本画布约2.5—3 pt起步 | 箭头头部与方向清晰，实际渲染后调整 |
| 页码 | 约12 pt，右下角 | 原生动态页序，不手填总页数 |

这些数值描述内置模板，不覆盖用户提供的新模板。容不下时先精简文案、调整图表空间，不把所有文字缩成小字。

## 上下句各自完成什么

上半部分引句先说本页最值得看的事实，图表负责证明，下半部分总结进一步解释。

- 引句可以报起止数值、同比变化、阶段特征、领先地区或完成的成果数量。
- 总结应回答“这说明什么、改善体现在哪里、有什么实际意义”。用“总体评价”可行，但不要每页只换几个词套用。
- 总结不反复写“开展了分析”“明确了特征”“提供了依据”，除非该页本身介绍方法与交付成果。
- 主张改善时标清比较基期、统计对象和方向。相对低值不自动等于效率高，单年回升不自动等于长期持续改善。
- 不把经济口径变化全部归功于技术节水，不把水面面积当成库容，不把空间估算当成实测用水、实际缺水或可直接实现的节水量。
- 不足控制在必要的短句内，但会改变判断的限制仍需保留。建议使用“仍有分类提升空间”“相关变化宜持续跟踪”等具体而适度的表述，不能虚构积极成效。

## 证据与来源

在选图前建立简短清单：材料位置、指标含义、空间尺度、年份、单位、数据性质和拟支撑的结论。

- 对照报告正文、表格与图件，发现冲突先查明，不凭视觉挑选更有利的数字。
- 不把不同统计口径的年度值直接拼成同质长序列。插补、估算、样本前沿和监测期占比须与独立观测、绝对效率和单年比例区分。
- 成果归属按用户确认的汇报分工，不因其他章节出现同一术语就在多个成果重复展开。
- 可删去重复的年份标签与制作说明，但图的单位、图例、关键时间口径、必需署名不能丢。
- 解释性限制放备注或配套Markdown。若删去某个限定会误导台上读图，则保留简短、可读的限定词，例如“空间估算”“监测期内”。

## 图表

- 趋势用折线，类别比较用柱状图，长地名优先横向柱图。原生表格只承载确实需要逐项阅读的内容。
- 对比图的分类、排序、单位、颜色和范围保持可解释的一致性。条形图从零起，百分比与底层数值格式对应。
- 同一图保持实际数据与标注一一对应。多年均值标注靠近其虚线，不漂在与线无关的角落，不压住曲线。
- 放映尺寸下检查年标、县名、数值、图例和轴刻度。不把自动跳过类别、裁掉长标签或刻度叠字当成可接受的压缩方式。
- 技术术语优先中文，必要时首次括号解释缩写。面向非专业汇报对象时，不单独留下未经解释的英文统计名。

## 地图与GIS动图

地图必须配一个明确的空间发现，例如集聚位置、变化方向或识别对象。完整保留有效范围、图例、单位和比例尺；不要裁去解释地图所必需的内容。

用户要求长时序动图时：

1. 先确认每个指标真实可比的年份、乡镇等单元边界与唯一编码。
2. 固定地图范围、分级阈值、色带和图例，缺失数据用独立符号表达。
3. 多图需要同步时，优先合成为一张多面板GIF，共用一条时间轴；单独插入多个GIF不能未经测试就宣称严格同步。
4. 面板数量和布局服从结论。可用两图、三图或其他适当组合，不强制3×3。
5. 采用较快节奏时，可从6—8秒一轮起步，具体根据年份数与讲解时长调整。首尾留出短暂停顿，时间轴清楚。
6. 平滑渐变可以通过视觉过渡实现，不称作真实“扩散过程”。过渡帧不能冒充中间年份实测值，说明留在备注或读图必需位置。
7. 保留时间轴后，不再叠加重复的“某年到某年”动态角标。2024年等单年专题之间切换不等于长时序。
8. 最后一年叠加的固定重点名单，应注明其所属年份和判定口径，不能假装每年重新识别。

沿用现成图件时先核查来源，不重算科学模型以凑动效。需要重新制图且环境有 `leezy-mapcraft` 时可以配合使用，但缺少该技能不妨碍采用合格的既有地图。

## 讲稿与展示

幻灯片呈现重点，口头解释放备注。备注可记录来源、口径、插补年份、方法限定和章节衔接，不必全部变成可见页脚。

放映测试与静态预览分开记录。GIF已打包、文件能打开、静态图片正常，不等于动画已在目标机器顺畅播放。
