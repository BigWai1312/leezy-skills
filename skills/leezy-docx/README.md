# LEEZY DOCX

**LEEZY Skills · BigWai1312 · 中文报告样式排版**

[技能源地址](https://github.com/BigWai1312/leezy-skills/tree/main/skills/leezy-docx) · [MIT 许可](LICENSE) · [来源声明](NOTICE.md)

把 Markdown 源稿、Word 命名样式、自动目录、题注和交叉引用组成可维护的报告流程。修改同类样式即可统一调整相应文字，避免逐段手工排版。

## 规则

- 只要求修改 Markdown 时不生成 DOCX；明确要求 Word 时再排版。
- 正文、各级标题、图题、表题、公式、目录、页眉页脚分别使用“修改的XXX”样式，保留已有内容和数据。
- “目录”黑体小二；一级目录黑体四号，其他目录宋体小四；单倍行距、逐级缩进、页码右对齐。
- 黑色三线表，透明底色：表头黑体、表内宋体，使用独立段落样式；上下粗线默认 1.5 pt，表头下细线 0.75 pt。
- 跨页重复完整表头和“续表××”，逐页核查上下粗线；保留自动编号与引用、原生可编辑公式。

完整参数见 [样式契约](references/style-contract.md)。本技能是 AI 工作规范，不是即装即用的 Word 加载项或通用转换程序。

## 安装

在支持技能安装器的 Codex 中输入：

```text
$skill-installer
从 BigWai1312/leezy-skills 安装 skills/leezy-docx，技能名称 leezy-docx。
```

或者下载 [Release](https://github.com/BigWai1312/leezy-skills/releases) 中的 `leezy-docx.zip`，
解压后将 `leezy-docx` 文件夹放到客户端扫描的 Skills 目录。
默认 Codex 安装位置是 `<CODEX_HOME>/skills/leezy-docx/`；
未设置 `CODEX_HOME` 时通常为用户主目录下 `.codex/skills/leezy-docx/`。
其他客户端以其实际配置为准。

确认结构为 `leezy-docx/SKILL.md`，不要嵌套为 `leezy-docx/leezy-docx/SKILL.md`。
重新打开会话后使用 `$leezy-docx`。更新前保留自己修改过的旧安装，不要直接覆盖。

若已有本地旧版报告排版技能，新调用名不会自动成为旧名的别名；
确认新版可用后再停用旧安装，避免重复发现。仓库不自动修改这些本地文件。

## 输入要求

| 输入 | 要求 |
| --- | --- |
| 源文件 | 明确提供权威 Markdown，或要调整的 DOCX |
| 任务阶段 | 仅改源稿、生成 Word、或只调整已有 Word 样式 |
| 输出位置 | 可写的工作目录与文件名；默认不覆盖输入 |
| 模板与例外 | 有指定模板、字体、目录层级或页面规格时说明 |
| 图片及表格 | 提供实际文件和相对路径；明确图题、表题和正文引用 |
| 运行环境 | 允许文件读写及执行；生成工具如 python-docx，域更新和排版渲染工具如 Word |

需要黑体、宋体和 Times New Roman 等字体。字体缺失时说明替代方案，不能声称与目标字体完全一致。
只有聊天能力时只能提供编辑建议或脚本，不能声称已生成或检查本地文件。
渲染工具不可用时报告限制；安装本技能不会自动安装 Python、字体或 Office 软件。

## 可直接使用的示例

以下示例采用包内虚构示例 [sample-report.md](examples/sample-report.md)，不含真实项目内容。
把该文件作为输入交给助手；路径相对于技能目录。

### 只修改 Markdown

```text
$leezy-docx
以本技能 examples/sample-report.md 为输入，在工作目录创建 sample-edited.md。
梳理标题层级，检查表题和公式引用，保留虚构示例的数据及含义。
这次只处理 Markdown，不生成 Word，不修改安装目录中的示例原件。
```

预期：一份修改后的 Markdown 和简短说明，不产生 DOCX。

### 生成可维护的 Word

```text
$leezy-docx
把本技能 examples/sample-report.md 排成工作目录中的 sample-report.docx。
保留示例声明，创建自动目录、原生公式与自动表题编号。
按样式契约应用“修改的XXX”样式，表头和表内文字独立控制。
更新域并渲染检查；工具不可用时说明未完成的检查。不要覆盖输入。
```

预期：可编辑 DOCX；目录、题注和引用为可更新对象。渲染截图仅作内部检查。

### 验证跨页表格

```text
$leezy-docx
在临时工作目录创建虚构的三列表格样例，行号从1开始，数据明确标为测试值。
补充测试行直到实际渲染至少跨三页，不向真实报告追加数据。
应用透明底色三线表：黑体表头、宋体表内；上下1.5磅，表头下0.75磅。
续页显示“续表××”并重复完整表头，检查每页粗顶线和粗底线。
另外在测试副本只改“修改的表头”，确认表体字体和字号不变。
记录实际渲染工具、页数、检查结果与限制。
```

预期：隔离的排版测试稿及检查结果；不是对任意报告分页都正确的承诺。

## 维护边界

段落样式不能修改图片内部文字、图片尺寸或节的页边距。
跨页效果取决于实际渲染；若必须拆分续表，后续修改字号或边距需要重新分页验证。
技能校验通过不等于已经测试所有 Word 版本。完整检查要求见 [SKILL.md](SKILL.md)。

作者署名属于技能，不自动添加到用户报告。分发技能请保留许可及来源文件。
